MODULE 01

逆解的三个挑战

多解 · 无解 · 奇异姿态

01同一个目标，多组解

把底座、肘部、目标连成三角形：肘部可以落在连线两侧，于是同一个末端位置对应两组关节角。程序算出角度后，还要检查关节是否越限、当前姿态离哪组解更近。

目标 (6,4)：θ₁=0°, θ₂=+90° 与 θ₁=67.38°, θ₂=−90° 均可达同一点

02有些目标没有解

工作空间是末端可达范围。目标距离 r 超过 L₁+L₂=10 cm，或小于 |L₁−L₂|=2 cm 时无解。注意：距离合格 ≠ 关节限位允许。

(11,0) → r=11 cm 超出伸展；(1,0) → r=1 cm 小于最小折叠

03奇异姿态让求解困难

手臂完全伸直时（θ₂=0°），可操作度 |det J| = L₁L₂·|sin θ₂| → 0，某些方向无法靠小幅关节转动实现，数值法在此处非常敏感。

目标 (10,0)：θ₂=0°，det J = 0 奇异
MODULE 02

两种求解思路

几何直接算角 vs 迭代逐步逼近

几何解析法 一步到位

r = √(x² + y²)
cos θ2 = (r² − L1² − L2²) / (2L1L2)
θ2 = ± arccos(cos θ2)
θ1 = atan2(y, x) − atan2(L2sinθ2, L1+L2cosθ2)
  • 本质：余弦定理解三角形（底座—肘—目标）
  • 优点：无迭代、精度高、可直接得到两组解
  • 局限：强依赖结构，换构型公式要重推；结构复杂时难以推导
  • 适用：本课平面二连杆这类结构清晰的模型

数值迭代法 逐步逼近

x = L1cosθ1 + L2cos(θ1+θ2)
J = ∂(x,y)/∂(θ1,θ2)
Δθ = JT(JJT + λ²I)−1(xd − f(θ))
θk+1 = θk + Δθ,  直到 ‖e‖ < ε
  • 本质：正解→误差→调角，反复迭代（牛顿/雅可比）
  • 优点：通用，不依赖闭式公式，复杂结构也能用
  • 局限：受初值、停止条件、奇异姿态影响，可能收敛到不同分支
  • 适用：复杂/冗余机械臂，或解析式难以推导时
