# 逆运动学求解演示 · 几何解析法 vs 数值迭代法

《机器人学基础与实践》3.3 逆运动学与求解验证 的交互式网页演示。

平面二连杆机械臂（L₁ = 6 cm，L₂ = 4 cm，工作空间 2 ~ 10 cm），在浏览器中实时演示：

- **几何解析法**：余弦定理解三角形，直接给出肘上 / 肘下两组闭式解
- **数值迭代法**：阻尼最小二乘牛顿迭代，逐步收敛并展示迭代轨迹、误差曲线
- **三大挑战**：多解、无解（工作空间）、奇异姿态（det J → 0）
- **正解回代验证**：关节限位检查 + 末端误差核对
- **末端方向控制**：沿坐标轴步进 → 逆解 → 驱动模型 → 正解刷新，失败时保持当前姿态

## 运行

直接双击打开 `index.html`，或起一个静态服务：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

单文件、零依赖，无需构建。
